# Maflun Academy Website

A single-page website for Maflun Academy (Malkali Farm, Mando, Kaduna, Nigeria).

## Files
- `index.html` — the whole site (HTML + CSS + JS in one file)
- `assets/logo.png` — the school crest, background removed

## Run it locally
Just double-click `index.html`, or open it in any browser. No build step, no dependencies.
